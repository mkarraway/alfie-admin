# alfie-admin

Life Admin Assist: a private chat bot for two people to capture to-dos, backlog items and reminders, with a calm daily digest at 08:00 on weekdays. You chat with it in Element (Matrix).

Built in small increments, tests first, so the chat provider, the text reader (rules parser or LLM) and the host machine can each be swapped later.
